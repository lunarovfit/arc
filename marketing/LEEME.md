# Material de ARC

- `appstore/` — capturas finales para la App Store (1290×2796, iPhone 6,7"). Orden: 01 nivel, 02 rutina, 03 registro, 04 vídeo, 05 músculos, 06 comidas, 07 hábitos.
- `raw/` — capturas originales de la app, para vídeos promocionales y YouTube.
  - Las que llevan `NO-APPSTORE` tienen personajes de anime: valen para redes, no para la tienda.
- `make_slides.py` — el script que monta las capturas (para rehacerlas con pantallas nuevas).
